# Algorithm Practice

백준 문제와 알고리즘 수업의 풀이를 Python, C, C++, Java로 정리했습니다.

## 폴더

- `IO`: 표준입출력
- `Conditional Statement`: 조건 분기
- `Algorithm Class`: 알고리즘 수업 구현
- `Etc`, `CapStone`: 기타 풀이와 연습

[소스 목록](docs/source-index.csv)에서 파일 위치를 찾을 수 있습니다. 같은 문제의 여러 시도와 미완성 풀이도 포함합니다.

## 실행

```bash
python path/to/solution.py < input.txt

g++ -std=c++17 path/to/solution.cpp -o solution
./solution < input.txt
```

각 파일을 독립적으로 실행합니다. Java는 선언된 클래스 이름에 맞춰 컴파일하며, 입력 형식은 해당 문제와 소스를 참고하세요.
