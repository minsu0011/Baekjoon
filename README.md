# 알고리즘 문제풀이

백준 문제와 알고리즘 수업의 풀이를 모았습니다. 입력 크기에 맞는 자료구조와 알고리즘을 선택하고 독립 프로그램으로 구현하는 연습입니다.

## 사용 기술

Python, C, C++, Java를 사용합니다. 표준 라이브러리와 표준입출력이 중심이며 문제마다 실행 단위가 다릅니다.

## 학습 흐름과 폴더

- `IO`: 입력을 읽고 요구 형식에 맞게 출력하는 연습
- `Conditional Statement`: 조건 분기와 경계 처리
- `Algorithm Class`: 알고리즘 수업 구현
- `Etc`, `CapStone`: 별도로 정리한 풀이와 연습

기초 입출력에서 시작해 풀이별로 필요한 연산을 구성했습니다. 문제마다 입력 형식과 시작점이 달라 하나씩 실행하며 따라갈 수 있도록 공통 실행기 없이 정리했습니다.

## 풀이를 읽을 때

입력 크기와 자료형을 확인하고 반복문이 몇 번 도는지 살펴보면 선택한 방법의 비용을 이해할 수 있습니다. 같은 번호의 여러 파일은 다른 풀이 시도일 수 있습니다. 중간 시도도 포함하므로 모든 파일을 정답 풀이로 보지는 않습니다.

## 실행 예

```bash
python path/to/solution.py < input.txt
g++ -std=c++17 path/to/solution.cpp -o solution
./solution < input.txt
```

C는 해당 파일을 개별 컴파일하고 Java는 선언된 class 이름으로 실행합니다. 필요한 입력은 소스의 입력 처리 부분에서 확인합니다.

[소스 목록](docs/source-index.csv)에서 파일 위치를 찾을 수 있습니다. 문제 원문과 채점 데이터의 권리는 문제 제공자에게 있습니다.
