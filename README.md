# Algorithm Practice
문제별 독립 프로그램으로 알고리즘과 표준입출력 구현을 학습한 기록입니다. 작은 풀이들을 별도 repository로 분리하지 않고 기존 이력을 유지합니다.

## 읽는 방법
[소스 인덱스](docs/source-index.csv)에서 언어와 경로를 찾을 수 있습니다. 각 파일은 독립 entrypoint이며 전체를 하나의 binary로 링크하는 프로젝트가 아닙니다. 동일 번호의 다른 구현은 학습 변형일 수 있어 파일명만으로 최신 정답을 판정하지 않습니다.

## 실행
Python 풀이: `python 경로/파일.py < input.txt`.
C/C++ 풀이: 해당 파일을 개별 컴파일한 뒤 표준입력으로 문제 입력을 제공합니다. Java 파일은 선언된 public class 이름과 실행 class를 확인해야 합니다.

## 검증과 결과
게시 단계의 검사는 코드 문법 및 선택된 작은 입력에 제한됩니다. 전체 문제를 온라인 저지에 재제출하지 않았고, 모든 풀이의 Accepted 상태를 주장하지 않습니다. 실행되지 않은 풀이의 정답성은 UNKNOWN입니다.

## 배운 점과 한계
입력 크기에 맞는 자료구조 선택, 인덱스 경계, 시간복잡도와 자료형 범위를 각각의 풀이에서 확인하는 것이 목적입니다. 문제 설명·대형 테스트 데이터·생성 binary는 새 게시 대상으로 삼지 않습니다. 문제 플랫폼과 과제 원문에 대한 권리는 각각의 원저작자에게 있습니다.
